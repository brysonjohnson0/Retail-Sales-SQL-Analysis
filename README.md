# Retail-Sales-SQL-Analysis
## Project Overview
Analyzed a retail sales dataset with nearly 10,000 retail transactions using SQL, SQLite, Python, and Pandas to identify sales trends, customer insights, and business performance.
The objective of this project was to demonstrate SQL proficiency while applying analytical thinking to answer business questions and support business decision-making.

**Dataset**


Sample Superstore Dataset

Imported into SQLite using Python and Pandas
Business Questions

**This project answers the following business questions:**

Which products generated the highest sales?
Which regions generated the highest sales?
Which customers generated the highest sales?
Which product categories generated the highest sales?
How did monthly sales change over time?
How did annual sales change over time?
Which customer segment generated the highest sales?
Which states generated the highest sales?
Which states generated the highest profit?

**Key Findings**

Technology was the highest-performing product category. -Continue investing efforts.
Consumer customers generated the most revenue. - Maintain focus on consumer segment while exploring oppurtunites to help home office sales grow.
California produced the highest sales and profit. -Prioritize.
Sales increased steadily from 2014 through 2017.
Regional analysis identified the West as the strongest-performing market.
